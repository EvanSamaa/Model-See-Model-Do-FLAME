# FLAME Model Files

Download from the [FLAME official website](https://flame.is.tue.mpg.de/) (free registration required):

1. **`generic_model.pkl`** — FLAME 2020 generic model
   - Download "FLAME 2020" and extract `generic_model.pkl`

2. **`FLAME_albedo_from_BFM.npz`** — BFM-based texture model
   - Available from the FLAME downloads page

3. **`landmark_embedding.npy`** — Landmark embedding for 68/105 landmarks
   - Available from the FLAME downloads page

4. **`FLAME_masks.pkl`** — Vertex masks for different face regions
   - Download from https://github.com/TimoBolkart/FLAME_masks

Place all four files in this directory (`pretrained_models/flame/`).
